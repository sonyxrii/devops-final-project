
ФІНАЛЬНИЙ ПРОЄКТ ВІД СОФІЇ ДУДКІНОЇ

Застосунок розроблено у рамках підсумкового практичного завдання та він реалізує повний цикл DevOps, підсумовуючи всю мою роботу протягом курсу. Було зроблено все згідно завдання:
- написано код на Node.js
- контейнеризація через Docker
- автоматична збірка та публікації у Docker Hub
- автоматичнк розгортання на хмарну інфраструктуру AWS за допомогою Terraform та GitHub Actions.


Структура мого проєкту:

• src/ — тут знаходиться вихідний код застосунку Node.js.
• infra/ — конфігурація Terraform для створення інстансу AWS EC2 та налаштувань мережі.
• .github/workflows/ — файли для автоматичного CI/CD пайплайну.
• Dockerfile — інструкції для створення оптимізованого Docker-образу.

Як запустити через Docker:

Спочатку зберіть Docker-образ:
docker build -t devops-final-app .

2. Потім запустіть контейнер:
docker run -p 3000:3000 devops-final-app

3. Після цього відкрийте в браузері адресу: http://localhost:3000



Інфраструктура проєкту описана в папці infra/ за допомогою Terraform. Цей код автоматично створює групу безпеки та віртуальну машину.

CI/CD Пайплайн налаштований у файлі .github/workflows/deploy.yml. Кожного разу, коли ви робите пуш в гілку main, пайплайн автоматично збирає Docker-образ, відправляє його в Docker Hub, створює інфраструктуру та оновлює застосунок на сервері.



Щоб CI/CD пайплайн працював, вам потрібно додати такі секрети в налаштуваннях репозиторію GitHub:

DOCKER_USERNAME — ваш логін у Docker Hub.
DOCKER_TOKEN — токен для доступу до Docker Hub.
AWS_ACCESS_KEY_ID — ваш ключ доступу до AWS для роботи Terraform.
AWS_SECRET_ACCESS_KEY — ваш секретний ключ AWS.
EC2_SSH_KEY_B64 — ваш приватний SSH-ключ, закодований у форматі Base64, для підключення до EC2.
